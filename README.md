# Youth Finance Hub on coeconomics.com

Australian Youth Financial Literacy & Economic Empowerment Hub (12 rooms).

**Domain:** [coeconomics.com](https://coeconomics.com)

Educational prototype for young Australians (approx. 15–34). Covers personal finance alongside structural and collective economic capability (tax, super, housing, cooperatives, CLTs, DGR, community wealth).

## Status
- `index.html` and `styles.css` updated to the Youth Finance Hub.
- Full interactivity requires `script.js` and `content.js` (push them to complete the working app).
- Previous Doug’s Lab structure notebook files remain in the repository for reference.

## Deploy (Cloudflare Pages)
1. Workers & Pages → Connect to Git → **v2-prog/dougs-structure-au**, branch `main`.
2. Framework: None. Build command: empty. Output directory: `/`.
3. Custom domain `coeconomics.com` (DNS on Cloudflare).

## Educational only
General financial education based on Australian official sources. Not personalised advice. Rules change — verify with ATO, ASIC Moneysmart, Services Australia, ACNC, etc.
